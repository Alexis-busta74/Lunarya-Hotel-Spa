#  Proyecto Final - Lunarya Hotel & Spa

Proyecto final para la materia PROGRAMACION 2, se trata de una pagina web completa para un hotel llamado **Lunarya Hotel & Spa**, este mismo incluye informacion las habitaciones, servicios, spa, reservas y más.
La idea fue diseñar una interfaz clara, visualmente atractiva y funcional, permitiendo que tanto clientes como administradores puedan interactuar con el sistema de manera intuitiva.

# Estructura del sitio

El proyecto lo dividimos en varias carpetas para poder mantener todo organizado y que sea practico a la hora de buscar algun archivo:

- **`/static/`** --> Contiene los archivos estáticos como estilos CSS, imágenes, íconos y scripts en JavaScript.
- **`/templates/`** --> Todas las páginas HTML del sitio (usando Flask).
- **`/PDF/`** --> Contiene un archivo con la descripción de los servicios del spa en formato PDF.
- **`app.py`** --> Este es el archivo principal de la aplicación Flask.
- **`contactos.db`** --> Base de datos SQLite donde se guardan las reservas y mensajes de contacto.
- **`requirements.txt`** --> Lista de dependencias necesarias para correr el proyecto.
- **`README.md`** --> Es este archivo.
